## MC自定义交易村民生成器

## 简介
这是一个基于 Python Tkinter 的图形界面程序，用于生成 Minecraft 1.19.2 版本的自定义交易村民 `/summon` 指令。  
你可以：
- 添加、修改、删除村民的交易（购买/出售物品，可设置数量、附魔）
- 通过中文名称选择物品和附魔（依赖外部 JSON 映射文件）
- 设置村民是否可移动（NoAI）
- 一键生成指令并自动复制到剪贴板

## 环境要求
- Python 3.8+（推荐 3.10）
- 操作系统：Windows / macOS / Linux（需支持 Tkinter）
- 无需额外第三方库（仅使用标准库 `tkinter`、`json`、`os`、`sys`）

## 文件准备
程序需要两个 JSON 文件来提供中文名称与 Minecraft ID 的映射：

### 1. MCitems.json
格式：
```json
{
  "石头": "stone",
  "草方块": "grass_block",
  "钻石剑": "diamond_sword",
  ...
}
```
键为中文译名，值为物品 ID（可省略 `minecraft:` 前缀，程序会自动补全）。

### 2. MCenchants.json
格式：
```json
{
  "锋利": "sharpness",
  "耐久": "unbreaking",
  "火焰附加": "fire_aspect",
  ...
}
```
键为中文附魔名，值为附魔 ID（同样可省略命名空间）。

> 将这两个文件放在程序相同目录下。如果启动时找不到文件或解析失败，程序会弹出文件选择对话框，可手动选择 JSON 文件。

## 运行方法
在终端或命令行中执行：
```bash
python main.py
```
（假设程序保存为 `main.py`，也可使用其他文件名）

## 使用指南

### 启动与加载
1. 程序启动后会自动尝试加载同目录下的 `MCitems.json` 和 `MCenchants.json`。
2. 若加载成功，窗口标题栏会显示正常，所有中文物品/附魔名称将出现在下拉框中。
3. 若加载失败，会提示错误并询问是否手动选择文件。
4. 可随时点击 **“重新加载JSON”** 按钮重新加载映射文件（修改 JSON 后无需重启程序）。

### 添加交易
1. 点击 **“添加交易”** 按钮，弹出交易编辑对话框。
2. 对话框包含多个标签页：
   - **购买物品1**：选择物品、数量（1-64），可添加多个附魔（可留空）。
   - **购买物品2（可选）**：勾选“启用购买物品2”后可编辑第二个购买物品；不勾选则交易仅需一个购买物品。
   - **出售物品**：选择村民出售给玩家的物品、数量及附魔。
   - **交易选项**：设置最大交易次数（`maxUses`）。
3. 添加附魔：
   - 在对应物品标签页中选择附魔名称和等级（1-255），点击 **“添加附魔”**。
   - 已添加的附魔会显示在列表中，可选中后删除。
4. 填写完毕后点击 **“保存”**，交易即被添加到主窗口的交易列表中。

### 修改交易
1. 在主窗口的交易列表中选中要修改的交易。
2. 点击 **“修改选中交易”**，弹出编辑对话框（已填充原有数据）。
3. 修改完成后保存，交易将更新。

### 删除交易
1. 在主窗口的交易列表中选中要删除的交易。
2. 点击 **“删除选中交易”**，确认后该交易被移除。

### 设置村民是否可移动
- 在主窗口底部勾选 **“村民不可移动 (NoAI)”**：
  - 勾选后生成的指令中 `NoAI:1b`，村民无法移动。
  - 不勾选则为 `NoAI:0b`，村民正常移动。

### 生成指令并复制
1. 确保交易列表中至少有一个交易。
2. 点击 **“生成指令并复制”**。
3. 生成的 `/summon` 指令会显示在下方文本框中，并自动复制到系统剪贴板。
4. 在 Minecraft 1.19.2 的聊天栏或命令方块中粘贴即可。

## 生成指令示例
```
/summon minecraft:villager ~ ~ ~ {VillagerData:{profession:"minecraft:farmer",level:1,type:"minecraft:plains"},NoAI:1b,Offers:{Recipes:[{buy:{id:"minecraft:stone",Count:1b},sell:{id:"minecraft:diamond",Count:1b},maxUses:12,rewardExp:1b}]}}
```

## 错误处理与提示
- **JSON 加载失败**：程序会弹出错误对话框并允许手动选择文件；若仍失败，请检查 JSON 格式是否为合法对象。
- **未知物品/附魔**：如果输入的中文名称不在映射表中，保存时会报错并阻止交易保存。
- **数量/等级无效**：必须是正整数（物品数量 1-64，附魔等级 1-255，最大交易次数 1-9999）。
- **重复附魔**：同一物品不能添加相同附魔两次。
- **未选择交易**：修改或删除时需要先选中列表中的交易。
- **空交易列表**：生成指令前必须至少添加一个交易。

## 注意事项
- 物品和附魔 ID 若未包含命名空间（如 `sharpness`），程序会自动补全为 `minecraft:sharpness`。若使用模组物品，需在 JSON 中提供完整命名空间（如 `create:blaze_burner`）。
- 附魔等级在指令中使用 `lvl` 字段（1.19.2 支持 `lvl` 表示等级）。
- 村民职业固定为 `farmer`，类型为 `plains`，等级为 `1`。如需修改，可手动编辑生成的指令。
- 程序生成的村民默认站在执行指令的位置（`~ ~ ~`），请确保执行时空间足够。

## 常见问题
**Q：下拉框中没有中文名称？**  
A：请确认 JSON 文件已正确加载，且键值对格式正确；点击“重新加载JSON”后再试。

**Q：生成指令后粘贴到 Minecraft 没反应？**  
A：请确认游戏版本为 1.19.2，且处于允许使用指令的模式（创造模式或启用作弊）。若指令过长，建议使用命令方块。

**Q：可以生成多个村民吗？**  
A：程序一次生成一个村民，但你可以多次执行生成的指令，或修改指令中的坐标。
